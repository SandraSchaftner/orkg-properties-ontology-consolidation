# Pinned to the versions the v1.1.0 evaluation was run with (2026-08-17, Python 3.14).

# The pins matter for reproducibility: this evaluation counts embedding similarities
# against a hard threshold, so it is sensitive to the numerical precision of the
# embedding model. transformers v5 changed the from_pretrained default to the dtype
# declared in the model config (bfloat16 for Qwen3-Embedding-8B), where v4 defaulted
# to float32 -- on the identical v1.0.0 ontology that moves the headline metric from
# 7.98 to 12.79 average search hits. Gold_Standard_evaluation.py therefore pins
# float32 explicitly and asserts it, but the library versions are pinned as well so a
# run reproduces rather than merely resembles the published numbers.
